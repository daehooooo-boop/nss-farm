# NAME SYNERGY — 브랜드 & 디자인 가이드

- 버전: PHASE 1 MVP
- 최종 수정: 2026-11-15 (흑백 리디자인)
- 적용 위치: 모든 토큰은 `src/app/globals.css`의 `@theme`에 정의하고, 컴포넌트는 토큰 이름으로만 색·폰트를 사용한다.

## 1. 브랜드

### 1.1 한 문장

> 이름은 한 사람이 가장 많이 듣는 소리다. NAME SYNERGY는 두 소리가 만나 만드는 관계를 읽어 준다.

### 1.2 성격

감성적 · 지적 · 세련된 · 따뜻한 · 현대적인 · 신뢰감 있는

| 이렇게 | 이렇게 하지 않는다 |
| --- | --- |
| 잡지의 피처 기사처럼 차분하게 | 운세 사이트처럼 신비롭게 |
| 근거를 보여주고 해석한다 | 단정하고 예언한다 |
| 다름도 가능성으로 말한다 | "궁합이 나쁩니다" |
| 여백과 큰 타이포로 집중시킨다 | 장식·이펙트로 채운다 |

### 1.3 키워드

Editorial Design · Modern Minimalism · Digital Magazine · Human Connection · Data Visualization

### 1.4 금지 시각 언어

전통 문양, 금색/금박, 붉은 인장, 구름·용·태극, 별자리·우주 배경, 타로/수정구 이미지,
과한 그라디언트·글로우, 이모지 장식.

---

## 2. 핵심 시각 아이디어: "두 개의 선, 하나의 교차"

- 사이트 전체는 **블랙 & 화이트 모노크롬**이다. 색 대신 채움과 선, 밝기 차이로 두 사람을 구분한다.
- **A = 검정 채움(solid)**, **B = 회색 외곽선(outline)**. 배지·이름·그래픽에서 이 규칙을 지킨다.
- A와 B가 섞이는 순간은 **조화 지수 링**과 **공유 이미지** 두 곳(검정→회색 그라디언트)뿐이다.
- 기본 그래픽 모티프: 두 개의 얇은 원이 겹치는 형태. 로고 심볼, 로딩, 점수 시각화에 일관되게 쓴다.

## 3. 색상

### 3.1 토큰 (2026-11-15 흑백 리디자인, 흰 배경)

| 토큰 | HEX | 용도 | 대비 (paper 위) |
| --- | --- | --- | --- |
| `paper` | `#FFFFFF` | 기본 배경 (흰색) | — |
| `surface` | `#FFFFFF` | 카드, 입력 필드 배경 (테두리로 구분) | — |
| `ink` | `#0A0A0A` | 본문·제목 기본 텍스트 | 19.8:1 |
| `ink-soft` | `#4D4D4D` | 보조 텍스트, 캡션 | 8.5:1 |
| `ink-faint` | `#6B6B6B` | 플레이스홀더, 메타 정보 (최소 13px) | 5.3:1 |
| `line` | `#E8E8E8` | 구분선, 카드 테두리 | 장식용 |
| `line-strong` | `#C4C4C4` | 입력 필드·칩 테두리 | 장식용 |
| `person-a` | `#0A0A0A` | Person A (검정 채움) | 19.8:1 |
| `person-a-tint` | `#F4F4F4` | Person A 배경 틴트 | — |
| `person-a-night` | `#FFFFFF` | night 블록 위 Person A | — |
| `person-b` | `#6E6E6E` | Person B (회색, 텍스트 가능) | 5.1:1 |
| `person-b-bright` | `#9E9E9E` | Person B 그래픽 전용 (텍스트 금지) | — |
| `person-b-tint` | `#FAFAFA` | Person B 배경 틴트 | — |
| `person-b-night` | `#A6A6A6` | night 블록 위 Person B | — |
| `night` | `#0A0A0A` | 반전 블록 배경 (결과 커버, 푸터): 검은 바탕에 흰 글자 | — |
| `success` | `#0A0A0A` | 복사 완료 등 긍정 피드백 | 19.8:1 |
| `danger` | `#C62828` | 입력 오류 문구 (유일한 유채색, 오류에만) | 5.6:1 |

- 시그니처 그라디언트 `synergy`: `linear-gradient(120deg, #0A0A0A, #6B6B6B)`. 조화 지수와 공유 카드에서만 쓴다.
- `night` 블록 위 텍스트는 `text-paper`를 쓰고, 불투명도는 **60% 이상**만 허용한다.

### 3.2 사용 비율

흰색 75% · 검정 텍스트 20% · 회색 5%. 유채색은 오류 문구 외에 쓰지 않는다.

### 3.3 테마

라이트 단일 테마다(`color-scheme: light`, `theme-color #FFFFFF`). 결과 커버와 푸터만 검은 `night` 반전 블록으로 대비를 만든다. 공유 카드와 OG 이미지는 흰 배경.

## 4. 타이포그래피

### 4.1 서체

| 역할 | 서체 | 로드 방식 | 비고 |
| --- | --- | --- | --- |
| 영문 디스플레이·큰 숫자 | **Space Grotesk** (400/500/700) | `next/font/google` | 기하학적 그로테스크, 이탤릭 쓰지 않음 |
| 한글 제목·워드마크·본문·UI | **Pretendard Variable** | `pretendard` dynamic-subset CSS | 제목은 800, 자간 -0.03em |
| eyebrow·메타 라벨 | **JetBrains Mono** (400/500) | `next/font/google` | 자간 0.12em |

CSS 변수: `--font-display`(Space Grotesk), `--font-serif-kr`(이름은 유지, 값은 Pretendard), `--font-sans`, `--font-mono`.

### 4.2 스케일 (모바일 → 데스크톱)

| 토큰 | 모바일 | 데스크톱 | 행간 | 서체 | 용도 |
| --- | --- | --- | --- | --- | --- |
| `display` | 44px | 88px | 1.0 | Space Grotesk | 조화 지수 숫자 |
| `h1` (홈) | 20px | 52px | 1.2–1.35 | Pretendard 800 | 히어로 카피 (모바일은 폼을 한 화면에 넣기 위해 작게) |
| `h1` (결과) | 30px | 52px | 1.25 | Pretendard 800 | 결과 헤드라인 |
| `h2` | 24px | 36px | 1.3 | Pretendard 700 | 섹션 제목 |
| `h3` | 18px | 22px | 1.4 | Pretendard 600 | 카드 제목 |
| `body-lg` | 17px | 19px | 1.7 | Pretendard 400 | 리포트 본문 |
| `body` | 15px | 16px | 1.65 | Pretendard 400 | 일반 본문, 입력 |
| `caption` | 13px | 13px | 1.5 | Pretendard 500 | 캡션, 보조 정보 |
| `eyebrow` | 11px | 12px | 1.4 | JetBrains Mono 500, 자간 0.12em | 섹션 라벨 (예: `01 — SOUND`) |

- 한글 본문은 `word-break: keep-all`, 기본 자간 -0.01em.
- 한 줄 길이: 본문 최대 34em.
- 숫자 데이터는 `tabular-nums`로 정렬.

### 4.3 에디토리얼 장치

- **섹션 번호 + 영문 eyebrow**: `01 — SOUND`, `02 — STRUCTURE`, `03 — MEANING`, `04 — TYPE`, `05 — STORY`.
- **풀 쿼트**: 리포트의 핵심 문장 하나를 Pretendard 700으로 크게.
- **가는 구분선**: 1px `line`, 섹션 사이 간격 큼.

### 4.4 첫 화면 규칙

이름 2개 입력, 관계 선택, `분석하기` CTA가 스크롤 없이 한 화면에 보여야 한다 (375×548 Safari 툴바 포함 화면 기준 CTA 하단 427px). 한자·뜻 입력은 토글 하나 뒤에 접어 둔다.

## 5. 레이아웃

- 브레이크포인트: 기본(모바일) / `md` 768px / `lg` 1024px / `xl` 1280px.
- 컨테이너: 최대 1120px, 좌우 패딩 20px(모바일) · 32px(md) · 48px(lg).
- 리포트 본문 컬럼: 최대 680px, 가운데 정렬.
- 간격 스케일(4px 기준): 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 · 128. 섹션 간 간격 모바일 64~96, 데스크톱 128.
- 그리드: 모바일 1열 → md 2열 → lg 12열(카드 4/6/12칸).

## 6. 컴포넌트 원칙

| 컴포넌트 | 규칙 |
| --- | --- |
| 버튼 Primary | 배경 `ink`, 글자 `paper`, 높이 56px(모바일) / 52px, 반경 999px(필), 아이콘은 우측 `ArrowRight` |
| 버튼 Secondary | 배경 투명, 1px `ink` 테두리 |
| 버튼 Ghost | 텍스트 + 밑줄, 보조 액션 |
| 카드 | 배경 `surface`, 1px `line`, 반경 20px, 그림자 없음(호버 시 아주 옅게) |
| 입력 필드 | 높이 56px, 반경 14px, 1px `line-strong`, 포커스 시 해당 Person 색 2px 링 |
| 관계 선택 | 칩(라디오 그룹), 선택 시 `ink` 배경 |
| Person 라벨 | 원형 배지 `A` / `B` + Person 색 |
| 점수 시각화 | 두 개의 겹치는 링: 바깥 링이 지수만큼 `synergy` 그라디언트로 채워짐. 세부 점수는 가로 바 |
| 자료 부족 상태 | 점선 테두리 카드 + `ink-faint` 텍스트 + "의미를 입력하면 분석할 수 있어요" 링크 |
| 토스트 | 하단 중앙, `ink` 배경, 2초 |

반경: 칩/버튼 999px · 카드 20px · 입력 14px · 작은 태그 8px.
아이콘: lucide-react, 선 두께 1.75, 크기 18/20/24. 장식 목적 아이콘 남용 금지.

## 7. 모션

- 기본 지속 시간 160~240ms, 이징 `cubic-bezier(0.2, 0.7, 0.2, 1)`.
- 허용: 페이드+8px 상승 등장, 점수 카운트업(최대 900ms), 링 채우기, 버튼 눌림.
- 금지: 패럴랙스, 반복 펄스, 화면 전체 전환 효과, 1초 넘는 연출(분석 진행 화면 제외, 최대 2초).
- `prefers-reduced-motion: reduce`이면 모든 모션을 즉시 상태로 대체.

## 9. 보이스 & 톤 (UI 카피)

- 존댓말 "~해요"체 기본, 리포트 본문은 "~합니다"체로 조금 더 단정하게.
- 짧게: 버튼 2~6자, 안내 문구 한 문장.
- 사용자를 탓하지 않는다: "잘못 입력하셨습니다" ✕ → "이름은 한글 2~5자로 입력해 주세요" ○.
- 결과는 단정 대신 관찰: "~한 경향이 보여요", "~하게 어울립니다".
- 숫자 옆엔 항상 이유를 붙인다.

## 10. 접근성 체크리스트

- 텍스트 대비 4.5:1 이상 (위 토큰 표 기준). `person-b-bright`는 텍스트에 쓰지 않는다.
- 색만으로 구분하지 않는다: Person A/B는 색 + `A`/`B` 라벨.
- 포커스 링: 2px, offset 2px, 항상 보이게.
- 터치 영역 최소 44×44px.
- 점수 시각화에는 `aria-label`("이름 조화 지수 87점") 제공.
- 진행 화면은 `aria-live="polite"`.
